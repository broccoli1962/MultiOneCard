# 원테이블 Official — 원카드 대비 변경점

흔한 **원카드(54장, 4문양)** 를 기준으로, 원테이블 Official이 다른 점만 적는다.  
현재 판정 정본은 [`spec.md`](spec.md), 플레이어용 전문은 [`README.md`](../README.md).

하우스룰마다 원카드가 갈라지는 항목은 「흔한 처리」로 적는다.

---

## 한눈에

| 항목 | 흔한 원카드 | 원테이블 Official |
|------|-------------|-------------------|
| 덱 | 52+조커 1~2, 보통 54장 | **91장** (고유 89종, 패스만 3장) |
| 문양 | ♠♥♦♣ | 6문양. **별·달(둘 다 청)** 추가 |
| 조커 | 대개 와일드 + 강한 공격 | **와일드 아님.** 본인 색일 때만. 흑+5 / 적+10 / 청+15 |
| 방어 | 대개 3만 | **3·4**, 같은 문양만. 죽창 top은 불가 |
| Q | 대개 Reverse만 | Reverse **또는** Give(다음에게 손패 1장) |
| K | 대개 한 장 더 | Extra(한 장 더) **또는** Hide(밑장, 효과 없음) |
| 무색 특수 | 없음 | 죽창·패스×3·역날검·리버스조커·미러·알약 3색 |
| 드로우 | 하우스룰 | 1장 뽑고 **턴 종료**(뽑은 장 같은 턴 불가) |
| 파산 | 없는 집이 많음 | 손패 **20장 이상 = 기권** |
| 턴 | 제한 없는 집 많음 | **15초**. 연속 타임아웃 3회 = 기권 |

---

## 덱 · 문양 · 색

트럼프는 **6문양 × 13랭크 = 78장**.

| 색 | 문양 |
|----|------|
| 흑 | 스페이드, 클로버 |
| 적 | 하트, 다이아 |
| 청 | 별, 달 |

별과 달은 색이 같아 **실루엣으로만** 구분한다. 같은 청이어도 문양이 다르면 「같은 문양」이 아니다.

시작 손패: 2~4인 **7장**, 5~6인 **5장**. 배분 후 덱 1장을 버리며, 특수여도 **효과 없음**.

---

## 조커 (3종, 와일드 아님)

원카드 조커는 아무 위에나 내고 큰 공격을 거는 집이 많다. Official은 그렇지 않다.

- 테이블 색(알약 락 → 7 지정 무늬 → 버림 top 색)이 **본인 색일 때만** 낸다.
- 예외: 일반 턴에 죽창·패스·역날검·미러가 top이면 조커를 포함해 **아무 색**이나 낼 수 있다.
- 조커 위 조커는 **색 무관**.
- 리버스 조커로 공격값만 순환한다. 이미 쌓인 스택은 바뀌지 않는다.

---

## 랭크 특수 — 원카드와 다른 점

유지되는 뼈대: 같은 무늬 또는 같은 랭크. 2=+2, A=+3, J=다음 1명 스킵, 7=문양 지정.

| 카드 | 원카드에서 흔한 처리 | Official |
|------|----------------------|----------|
| **3 · 4** | 3만 방어인 집 많음. 4는 숫자 | 둘 다 방어. **같은 문양만**. 평소는 일반 장 |
| **7** | 아무 7이 와일드처럼 쓰이는 집 있음 | 와일드 **아님**. 다른 랭크 위에서는 테이블 색과 맞을 때만. **7 위 7은 색 무관** |
| **Q** | Reverse만 | Reverse 또는 Give. Give는 같은 문양 3·4로 막음. 중첩 없음 |
| **K** | 한 장 더 | Extra 또는 Hide. 숨길 장이 없으면 Hide 불가 |

마지막 장이 합법이면 공격·Q·K여도 **즉시 1위**. 효과는 적용하지 않는다.

---

## 무색 특수 (원카드에 없음)

일반 턴(알약 락 없음)에서는 **아무 위에도** 낸다. 알약 락 중에는 무색 불가(해당 색 알약으로 락을 거는 수는 가능).  
공격 응답에서 낼 수 있는 무색은 **죽창 · 패스 · 역날검**뿐이다.

| 카드 | 효과 |
|------|------|
| **죽창** | 공격 +5. 3·4 불가. 패스·역날검·감수 가능. 스택에 한 장이라도 있으면 죽창 속성 유지 |
| **패스** ×3 | 공격 응답 전용. 스택을 유지한 채 다음에게 넘김. Q에는 불가. 일반 턴에도 불가 |
| **리버스 조커** | 조커값 순환 `BW ← COLOR ← MOON ← BW` |
| **역날검** | 공격 응답 전용. 직전 활성에게 `2×스택` 새 응답. 체인당 1회 |
| **미러** | 낸 뒤 내 손패 N에 맞춰 다른 좌석을 맞춤. 마지막 장이면 1위, 효과 없음 |
| **알약** 흑/적/청 | 1장 드로우 후 그 색만 내게 락. 7 무늬보다 우선. 그 색을 **실제로 내면** 해제 |

---

## 공격 이어가기 · 덮기

원카드는 「같은 랭크만」 또는 「아무 공격 카드」로 갈라지는 집이 많다.

Official:

- 2·A 이어가기: **같은 랭크**(색·문양 무관) **또는 같은 문양**. 클로버 A → 하트 A 가능, 하트 A → 하트 2 가능, 달 A → 별 2 불가.
- 조커 위 2·A는 테이블 색과 본인 색이 같을 때만.
- **패스·역날검으로 덮이면** 2·A·조커·3·4는 색·문양·랭크 무관. 죽창 top은 3·4 불가.
- 덮기 전 3·4는 색이 같아도 문양이 다르면 불가(별 2 → 달 3 불가).
- Official은 조커 공격을 **같은 색 3·4로** 막을 수 있다.

공격과 Q Give는 **동시에 열리지 않는다**.

---

## 진행 · 승패 · AFK

- 합법 수가 있어도 드로우를 고를 수 있다. Official은 1장 뽑고 턴을 넘긴다.
- 손패 0 = 즉시 1위. 잔여 순위전 없음(커스텀 `ContinueAfterFirstWin`만 예외).
- 나머지는 잔여 장수 오름차순, 동률이면 점수 낮은 쪽.
- **손패 20장 이상 = 파산.** 기권과 같다(활성 제외, 최하위, 손패는 버림에 넣음).
- 연속 타임아웃 3회 = 기권. 재접속 유예 45초.

---

## 매칭 (규칙 판정 밖)

카드 판정은 아니지만, 로비 동작이 기획 초안과 다르다.

- **퀵매치·LAN 없음.** 방 만들기, 6자리 룸코드, 공개 방 목록으로만 입장.
- 현재 방은 **Official 고정.** 커스텀 하우스룰 필드는 코드에만 있고 방장 편집 UI는 숨긴다.
- 재대결 20초, **전원 찬성**이면 즉시 새 판. 호스트가 나가면 알림.

## Official 확정 패치

구현 이후 판정이 바뀐 항목. 예전 「무색 top이면 조커 불가」「2·A는 같은 랭크만」은 폐기한다.

| 시점 | 내용 |
|------|------|
| 파산·기권 | 손패 20장 파산. 기권·파산 시 손패를 버림에 넣음. Q 초과 기본은 Reverse |
| 패스·역날검·죽창 top | 일반 턴 무색 wild top이면 조커·7 포함 아무 색. 공격 중 패스·역날검 덮기 후 2·A·조커·3·4는 색 무관. 2·A 이어가기에 같은 문양 허용 |
