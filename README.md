# 원테이블 (OneTable)

확장 트럼프 **91장**으로 치는 원카드. Android / iOS / Windows가 **같은 방**에서 대전하고, 대기실부터 결과 화면까지 **텍스트 채팅**으로 대화한다.

본편은 **항상 온라인 멀티**. 승패·손패·덱은 서버(또는 동일 RuleEngine)가 판결하고, 클라는 의도만 보낸다. 카드는 고정 91장이며 가챠·시즌 카드·성장은 없다.

구현·판정 세부는 [`Docs/spec.md`](Docs/spec.md)가 기준이다.

브라우저 플레이: https://broccoli1962.github.io/MultiOneCard-web/  
소스 저장소가 private 이라 WebGL 은 공개 저장소 [MultiOneCard-web](https://github.com/broccoli1962/MultiOneCard-web) 으로 호스팅한다.

---

## 한 판의 목표

손패를 **0장**으로 만들면 즉시 1위. 공격·Q·K여도 마지막 장이 합법이면 피니시다. 효과는 적용하지 않는다.

나머지는 잔여 손패 장수 오름차순, 동률이면 점수 낮은 쪽이 앞선다. 기권은 최하위.

---

## 진행

| 항목 | Official |
|------|----------|
| 인원 | 2~6인 |
| 시작 손패 | 2~4인 7장, 5~6인 5장 |
| 선 | 난수 좌석 |
| 방향 | 반시계(+1) |
| 턴 | 15초, 한 턴 1장 (예외: K Extra) |
| 시작 | 배분 후 덱 1장을 버림. 특수여도 **효과 없음** |

덱이 고갈되면 버림 top 1장만 남기고 나머지를 셔플한다. 그래도 없으면 그 드로우는 실패하고 턴만 넘긴다.

합법 수가 있어도 **드로우를 고를 수 있다**. Official은 1장 뽑고 **턴을 넘긴다**(뽑은 장이 합법이어도 같은 턴에 낼 수 없다).

---

## 덱 (91장)

고유 정의 89종 / 인스턴스 91장. 패스만 3장이다.

### 문양과 색

트럼프는 **6문양 × 13랭크 = 78장**.

| 색 | 문양 |
|----|------|
| 흑 | 스페이드(S), 클로버(C) |
| 적 | 하트(H), 다이아(D) |
| 청 | 별(R), 달(M) |

별과 달은 둘 다 청이므로 **실루엣으로 구분**한다.

### 조커 3종

조커는 **와일드가 아니다**. 테이블 색(알약 락 → 7 지정 무늬 → 버림 top 색)이 **본인 색일 때만** 낸다. 버림이 무색이면 조커 불가.

| 카드 | 색 | 기본 공격값 |
|------|----|-------------|
| 흑 조커 (`JOKER:BW`) | 흑 | +5 |
| 적 조커 (`JOKER:COLOR`) | 적 | +10 |
| 청 조커 (`JOKER:MOON`) | 청 | +15 |

조커 공격값은 리버스 조커로 순환할 수 있다. 이미 쌓인 스택은 바뀌지 않는다.

### 무색 특수 (10장)

죽창, 패스×3, 리버스 조커, 역날검, 미러, 알약(흑/적/청).

일반 턴(알약 락 없음)에서는 **아무 위에도** 낼 수 있다. 알약 락 중에는 무색을 낼 수 없다(해당 색 알약으로 락을 거는 수는 가능).

---

## 기본 수

버림 top과 **같은 무늬 또는 같은 랭크**.

- 무색은 알약 락이 없으면 와일드.
- 7은 와일드가 아니다. 다른 랭크 위에서는 테이블 색과 본인 색이 같을 때만 무늬·랭크 매칭. **7 위 7은 색 무관**.
- 버림 top이 색 있는 조커면 그 색 문양·같은 색 조커·알약만 가능.

---

## 랭크 특수

| 카드 | 효과 |
|------|------|
| **2** | 공격 +2 |
| **A** | 공격 +3 |
| **3 · 4** | 평소는 일반. 공격 응답에서 스택을 0으로. **같은 문양만**. 죽창 top이면 불가. Q Give도 같은 문양으로 방어 |
| **7** | 내고 6문양 중 하나를 지정. 초과 시 낸 7의 원래 무늬 |
| **J** | 다음 활성 1명 스킵 |
| **Q** | Reverse(방향 반전) 또는 Give(다음 활성에게 손패 1장). Give는 대상이 같은 문양 3·4로 막을 수 있다. 중첩 없음. 초과·마지막 Q는 Reverse / 효과 없음 |
| **K** | Extra(합법 1장 더. 또 K면 재선택) 또는 Hide(아무 1장을 K 밑, 효과 없음, 앞면 비공개). 숨길 장이 없으면 Hide 불가 |

### 공격 이어가기

2·A 이어가기는 **같은 랭크만**(색·문양 무관). 예: 클로버 A → 하트 A 가능, 달 A → 별 2 불가.

조커 위 2·A는 테이블 색과 본인 색이 같을 때만. **조커 위 조커는 색 무관**. 3·4는 색이 같아도 문양이 다르면 불가(별 2 → 달 3 불가).

Official은 조커 공격을 **같은 색 3·4로 막을 수 있다**.

---

## 무색 특수 효과

공격 응답에서 낼 수 있는 무색은 **죽창 · 패스 · 역날검**뿐이다.

| 카드 | 효과 |
|------|------|
| **죽창** | 공격 +5. 3·4 불가. 패스·역날검·감수 가능. 스택에 한 장이라도 있으면 죽창 속성이 유지된다 |
| **패스** | 공격 응답 전용. 스택을 유지한 채 다음 활성에게 넘김. Q에는 사용 불가 |
| **리버스 조커** | 조커값 순환 `BW ← COLOR ← MOON ← BW`. 공개 top은 이 장(와일드) |
| **역날검** | 공격 응답 전용. 직전 활성에게 `2×스택` 새 응답. 체인당 1회 |
| **미러** | 낸 뒤 내 손패 N장에 맞춰 다른 좌석을 조정(초과는 선택 버림·효과 없음, 부족은 드로우). 마지막 장이면 1위, 효과 없음 |
| **알약** | 1장 드로우 후 해당 색만 낼 수 있게 락. 7 무늬보다 우선. 그 색을 **실제로 내면** 해제. 드로우 때문에 알약 단독 피니시는 없다 |

---

## 공격 / Q 체인

공격과 Q Give는 **동시에 열리지 않는다**.

**공격 응답:** 전이(공격 카드) / 패스 / 역날검 / 방어(3·4) / 감수(스택 전부 드로우, 추가 수 없음).

**Q Give:** 대상이 같은 문양 3·4로 막거나 감수. 감수하면 낸 사람이 손패 1장을 고른다. 지급 후 0장이면 1위, 아니면 받은 좌석의 턴.

---

## 파산 · 타임아웃 · 재접속

- **손패 20장 이상 = 파산.** 기권과 같다(활성 제외, 순위 최하위, 손패는 버림에 넣음).
- **연속 타임아웃 3회 = 기권.**
- 재접속 유예 **45초**. 초과 시 기권.
- 초과 시 기본 처리: 일반=드로우 1, 공격=스택 전부, Q 선택=Reverse, K 선택=K만 내고 종료.

---

## 점수 (동률·자동 선택)

타임아웃 때 어떤 장을 고를지, 순위 동률을 가를 때 쓴다.

| 카드 | 점수 |
|------|------|
| 5~10 | 숫자 그대로 |
| J | 10 |
| A | 15 |
| 2 / 3 / 4 / 7 / Q / K | 20 |
| 패스 · 알약 | 25 |
| 흑·적 조커 | 30 |
| 청 조커 · 리버스 조커 · 미러 | 40 |
| 역날검 | 45 |
| 죽창 | 50 |

## 조작

카드를 **테이블 쪽으로 드래그**해서 낸다. 탭은 미리보기·선택만. PC는 Enter로 선택한 장을 낸다.

| 동작 | 입력 |
|------|------|
| 드로우 | 덱 또는 `D` |
| 문양 지정 | 6버튼 또는 `S` `H` `D` `C` `R` `M` |
| Q | Reverse `R` / Give `G` |
| K | Extra `E` / Hide `H` |
| 퀵챗 | `F1`~`F8` |
| 해제 | Esc / 우클릭 / 빈곳 |

합법 카드는 밝게, 불법은 어둡고 선택할 수 없다. 서버 ack까지 입력은 잠긴다.

---

## 매칭 · 채팅

- 퀵매치 2/4/6인, 또는 6자리 룸코드로 방 참가.
- 대기실에서 준비, 방장이 시작. 인원 2명 이상. 시작 후 난입 없음.
- 결과에서 재대결 20초. **전원 찬성**이면 즉시 새 판.
- 채팅: 대기실·인게임·결과. 음성 없음. 본문 최대 80자.
- 퀵챗 8개: 나이스, 수고, 빨리, 가자, 실수, 대박, 고마워, 한판더.
