# Aseprite sprite draw

사용자가 생성본을 그대로 잘라 쓰라고 명시한 때만 크로마키를 쓴다.

## 금지

- 생성 픽셀을 최종 스프라이트에 남기지 않는다
- 마젠타/`#FF00FF`/크림키/`erase_color`로 배경을 따지 않는다
- `rembg`와 소프트 매트 금지
- 빈 캔버스에 `fill_area` 금지 (투명 픽셀이 전부 채워진다)
- 캔버스 전체에 배경색을 깔지 않는다

## 절차

1. **참고 이미지 (선택)**  
   복잡한 형상만 사용 가능한 이미지 생성 도구를 쓴다. 프레임·배지·게이지는 생성 없이 바로 3으로.  
   프롬프트에 마젠타/크로마키/transparent background를 넣지 않는다. 구도·실루엣만 요청한다.

2. **캔버스**  
   `create_canvas`로 RGB 캔버스를 만든다. 빈칸은 알파 0으로 둔다.

3. **참고 레이어**  
   생성본이 있으면 `import_image_as_layer`로 맨 아래에 넣는다.  
   불투명도를 낮추고, 그리기가 끝나면 숨기거나 삭제한다.

4. **빈칸 → 덩어리 → 음영 → 외곽선**  
   새 레이어에만 그린다.
   - 빈칸: 배경을 칠하지 않는다
   - 덩어리: 실루엣만 불투명하게
   - 음영: 덩어리 안에서만
   - 외곽선: 마지막에 `outline_cel` (불투명 픽셀 옆의 투명 칸만)

5. **보내기**  
   참고 레이어가 꺼진 상태로 `export_sprite` / `export_frame`.  
   스케일 8–10 PNG를 열어 구멍·남은 생성 픽셀·불투명 배경이 없는지 확인한다.

## 도구

현재 연결된 Aseprite MCP의 도구 설명을 조회하고 지원되는 호출을 사용한다. Unity 경로·컷아웃 스크립트에 의존하지 않는다.
최종 파일 위치는 현재 프로젝트에서 받는다.
